# PawLog 设计语言(design-language)

> 版本:v1.1(2026-07-31,合并 landing 定稿,新增 §10 Web 令牌)。本文件是所有界面视觉的唯一依据,
> iOS 工程师按此实现;改动视觉先改本文件,再改代码。
> 效果预览:`design/preview/design-tokens.html`(源码,可改参数重出)→ `design-tokens.png`。
> 适用范围:iOS app 界面、app 图标延展、landing page、分享图与成长视频封面模板。

## 0. 设计原则

PawLog 是给新手宠物主的「成长时间胶囊」。视觉气质排序:

1. **温暖**:暖色底、奶油质感,不用冷灰冷蓝做氛围色。
2. **柔软**:圆角偏大、阴影轻、动效用弹簧,不做硬边硬跳变。
3. **克制**:品牌色只点在关键处(主行动、情感数字、里程碑),照片永远是主角,
   界面退后。不堆贴纸、不用廉价卡通元素。
4. **经得起回看**:产出物(对比图/成长视频)是会被保存和分享的「作品」,
   按纪念品标准做,不做工具感黑底字幕条。

## 1. 色彩系统

所有色值以 OKLCH 定义(感知均匀,便于深浅模式推导),sRGB hex 为实现值。
命名即 Assets.xcassets 中的 colorset 名(`paw` 前缀),SwiftUI 里用 `Color.pawPrimary`。

### 1.1 品牌色

| 令牌 | 浅色 | 深色 | OKLCH(浅/深) | 用途 |
|---|---|---|---|---|
| `pawPrimary` | `#E28D4F` | `#F3A768` | oklch(0.72 0.13 55) / oklch(0.79 0.12 60) | 暖阳杏。全局 tint:主按钮、Tab 选中、链接、图表主线 |
| `pawPrimaryStrong` | `#A45C31` | `#F3A768` | oklch(0.55 0.11 50) / 同上 | 文字级着色(白底上 pawPrimary 对比度仅 2.6:1,凡「带颜色的文字」一律用 Strong,对比度 5.1:1) |
| `pawPrimarySoft` | `#F8EED5` | `#3E332C` | oklch(0.95 0.035 90) / oklch(0.33 0.02 55) | 品牌色浅底:选中态底、徽章底、空状态图标底 |

来源:沿用 app 图标暖杏渐变(`#F6BA7C → #EB9C79`,oklch 0.83/0.76、色相 66/45),
取中间相位移深得到可点按的主色。图标、界面、产出物同源。

### 1.2 中性色(暖调,禁用纯灰/纯黑做氛围)

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `pawBg` | `#F8F5F0` | `#1E1712` | 页面背景(奶油白 / 暖墨) |
| `pawSurface` | `#FFFFFF` | `#2E241E` | 卡片、表单行、弹层 |
| `pawFill` | `#EEE9E1` | `#3E332C` | 占位填充(照片占位、头像占位、骨架屏) |
| `pawText` | `#30271F` | `#EBE7E0` | 主文字(暖黑,不用纯黑) |
| `pawTextSecondary` | `#6C6158` | `#A89C90`* | 辅助文字(浅底对比度 5.5:1) |
| `pawSeparator` | pawText @ 8% | pawText(dark) @ 12% | 分隔线、描边 |

\* 深色次要文字 = oklch(0.68 0.02 60),与深色底对比度 ≥ 4.5:1。

> 现状迁移:`Color(.systemGray5/6)` 全部换成 `pawFill`;硬编码 `.black/.white`
> 仅限相机取景页(沉浸式黑底场景允许),产出物按 §6 改造。

### 1.3 语义色

| 令牌 | 浅色 hex | OKLCH | 用途 |
|---|---|---|---|
| `pawSuccess` | `#5AA26B` | oklch(0.65 0.11 150) | 成功(已保存、已生成),苔绿不用荧光绿 |
| `pawWarning` | `#DDB049` | oklch(0.78 0.13 85) | 图形级提醒(图标、标记块) |
| `pawWarningText` | `#8D5E00` | oklch(0.52 0.11 75) | 文字级提醒(如「保存将覆盖更新」,对比度 5.6:1) |
| `pawError` | `#CB4930` | oklch(0.58 0.17 33) | 错误与 destructive(暖红,对比度 4.6:1) |
| `pawMilestone` | `#E4B750` | oklch(0.80 0.13 85) | 里程碑星金(图标),取代系统 `.yellow` |
| `pawMilestoneSoft` | `#F8EED5` | oklch(0.95 0.035 90) | 里程碑图标浅底,取代 `yellow.opacity(0.15)` |

规则:语义色只做信号,不做装饰;同一屏语义色不超过两种。

### 1.4 对比度红线

- 文字 ≥ 4.5:1(辅助文字同),大标题(≥24pt)≥ 3:1;
- 图标/控件图形 ≥ 3:1;深浅两版令牌必须分别达标(上表均已验证)。

## 2. 字体与层级

系统字 SF Pro,不引三方字体。**情感数字用 rounded 变体**,是唯一允许的字重装饰。

| 层级 | 规格 | 用途 |
|---|---|---|
| 情感大数字 | `.system(.largeTitle, design: .rounded, weight: .bold)` | 「在一起第 N 天」、小组件天数、产出物封面数字 |
| 页面标题 | 导航栏大标题(系统 largeTitle) | 四 Tab 首页 |
| 卡片/行标题 | `.headline`(17 semibold) | 记录日期、宠物名 |
| 正文 | `.body`(17) | 备注、表单内容 |
| 辅助 | `.subheadline`(15) | 次要信息(品种、体重数值) |
| 说明 | `.footnote`(13) | 提示、状态消息 |
| 标签 | `.caption`(12) | 徽章、产出物标注 |
| 数字 | 一律 `.monospacedDigit()` | 体重、天数、百分比,防跳动 |

- 日期格式统一走 `Date+PawLog`,不新增格式。
- 全部层级支持 Dynamic Type;自定义尺寸只允许出现在产出物(固定画布)中。

## 3. 间距与圆角

### 3.1 间距(4pt 网格,只允许下列值)

`4 / 8 / 12 / 16 / 20 / 24 / 32`

- 屏幕水平边距:20(列表行内系统默认即可,自定义布局用 20)
- 卡片内边距:16;卡片间距:12
- 行内元素间距:8(图标-文字)/ 12(图-文块)
- 区块间距:24;页面级大留白:32

### 3.2 圆角(连续圆角 `RoundedRectangle(style: .continuous)`)

| 半径 | 用途 |
|---|---|
| 8 | 小元素:标签、芯片、小按钮 |
| 12 | 缩略图(时间线 64pt 照片、里程碑图标块、选择网格) |
| 16 | 卡片、表单弹层内的图(记录编辑页 200pt 照片) |
| 20 | 产出物卡片(对比图、视频封面) |
| 胶囊 | 主行动按钮、相机页浮层控件 |

头像一律正圆。嵌套圆角遵守同心原则:外半径 ≈ 内半径 + 间距。

## 4. 组件状态

| 状态 | 规则 |
|---|---|
| 默认 | 主按钮 = pawPrimary 填充胶囊 + 白字;次按钮 = pawPrimarySoft 底 + pawPrimaryStrong 字 |
| 按下 | 不加深色,用 `scale(0.97) + opacity 0.85`,弹簧回弹(见 §5) |
| 禁用 | 整体 opacity 0.4,不另配灰色;附原因说明(如「还差 N 张照片」) |
| 加载 | 品牌场景用 `ProgressView` + pawPrimary tint;产出物合成给进度文案 |
| 空状态 | 三件套:符号图标(pawPrimarySoft 圆底 + pawPrimary 图标,64pt)+ 一句话标题 + 一个主按钮。文案要「陪伴感」,示例:「还没有成长记录 — 每天一张照片,见证豆豆的长大」 |
| 错误 | pawError 文字 + `.footnote`,就地展示,不用 alert 打断非阻断错误 |

- 表单主按钮(保存/创建)统一「胶囊主按钮」,与列表型按钮(borderedProminent)二选一,
  全 app 一致——v1 定为:列表/网格页用 `.borderedProminent`(tint pawPrimary),
  表单底部主行动用全宽胶囊。

## 5. 微动效基调

- 默认动画:`spring(response: 0.35, dampingFraction: 0.8)`,不用 linear。
- 列表增删:`.snappy` + 透明度过渡;页面浮现:8pt 位移 + 淡入。
- 情感时刻允许一次「庆祝感」:里程碑保存成功、对比图生成完成,可加重音动画
  (scale 1.0→1.05→1.0),一天最多触发一次的克制。
- `Reduce Motion` 开启时全部降级为 0.2s 淡入淡出,位移/缩放归零。
- 相机叠加层透明度滑杆无动画(跟手);快门按钮按下 scale 0.9。

## 6. 产出物模板(对比图 / 成长视频)

产出物是分享门面,按纪念品做,不出现纯黑底 + 白字幕的「监控录像感」。

### 6.1 对比图(1080pt 逻辑宽,scale=2 输出)

- 画布底:pawBg(浅色产出物固定用浅色版,保证任何分享场景一致)。
- 两侧照片:维持「完整显示 + 同图模糊放大填充」,照片外圆角 20,间距 16。
- 底部信息条:奶油底(pawSurface)+ pawText 文字 `.caption`,内容保持
  「日期 · 年龄/到家天数」;左下角落款 `PawLog` 字标(caption、pawTextSecondary),
  不加水印大图。
- 整体卡片圆角 20,导出即带圆角(分享时更柔和)。

### 6.2 成长视频(1080×1920,30fps)

- 照片填充:黑底改为暖墨底 `#1E1712`(pawBg 深色值,固定不变)。
- 字幕:白粗体改为奶油白 `#EBE7E0`、rounded semibold 56px,
  底部加 40% 暖墨圆角底条(半径 28,内边距 24×12),位置在安全区上方 260px。
- 转场:维持 0.2s 淡入淡出;首尾各加一帧 0.8s 品牌帧(首帧:宠物名 + 开始日期;
  尾帧:「PawLog · 一起长大的日子」+ pawPrimary 爪印),v1.1 实施,本版先立项。

## 7. 桌面小组件

- `containerBackground` 改 pawSurface(浅)/ pawSurface(dark),不用 `.fill.tertiary`。
- 天数数字用情感大数字规格(rounded bold)+ pawPrimaryStrong;宠物名 caption 次要色。
- 无照片占位:pawFill 圆 + pawPrimary pawprint,不用 secondary 灰。
- systemMedium 版式:左照片圆 56pt,右「第 N 天 / 名字」纵向排列,间距 12。

## 8. App 图标

现有图标(暖杏渐变 + 白爪印)方向正确,保留为 v1 图标。迭代方向(后续单独立项):
爪印造型精修(趾垫比例、掌垫曲线)、渐变增加轻微径向光感;遵守 1024×1024、
安全区内构图、无文字。

## 9. 落地约定(给 iOS 工程师)

1. 在 Assets.xcassets 建立 §1 全部 colorset(深浅双值),`UIColor` 动态色一处定义。
2. `project.yml` 或 App 层设全局 `tint = pawPrimary`;文字级着色用 `pawPrimaryStrong`。
3. 设计常量集中在 `Shared/Utilities/DesignTokens.swift`(圆角、间距、动效),界面只引用常量。
4. 改完跑 `xcodegen && xcodebuild build + archive` 零警告;深浅两模式模拟器截图回贴 issue。

## 10. Web 令牌(landing page)

landing page(`landing/index.html`)与 app 同源:主色同为暖阳杏、底色同为奶油白、
文字同为暖棕灰,仅命名按 web 习惯用阶梯刻度。CSS 先写 hex 兜底、再写 `oklch()` 覆盖。

### 10.1 配色

主色:暖阳杏(Apricot),对应 app 的 `pawPrimary` 一族。

| Token | OKLCH | 参考 hex | 用途 |
|---|---|---|---|
| `apricot-300` | `oklch(0.88 0.08 68)` | `#F8D6AD` | 浅色强调面、选中底 |
| `apricot-400` | `oklch(0.83 0.11 62)` | `#F4BE85` | 渐变亮端、插画主色 |
| `apricot-500` | `oklch(0.78 0.12 55)` | `#EEA268` | **品牌主色**:主按钮、关键强调 |
| `apricot-600` | `oklch(0.70 0.13 45)` | `#E0875F` | 按压态、渐变暗端、深底上的强调 |
| `apricot-700` | `oklch(0.55 0.11 45)` | `#B0633F` | 杏色上的文字(对比度达标时用) |

底色:奶油白(Cream)。

| Token | OKLCH | 参考 hex | 用途 |
|---|---|---|---|
| `cream-50` | `oklch(0.975 0.012 80)` | `#FBF6EF` | **页面主底色**(不用纯白) |
| `cream-100` | `oklch(0.955 0.018 75)` | `#F4EBDF` | 次级底、卡片衬底 |
| `peach-100` | `oklch(0.94 0.035 65)` | `#F9E4D2` | 杏色系浅面,插画/空状态 |

暖调中性色(Ink):所有文字与描边用暖棕灰,不用纯黑纯灰。

| Token | OKLCH | 参考 hex | 用途 |
|---|---|---|---|
| `ink-900` | `oklch(0.32 0.02 55)` | `#463728` | 标题、正文强调 |
| `ink-600` | `oklch(0.50 0.02 60)` | `#7C6B59` | 正文、次级信息 |
| `ink-400` | `oklch(0.65 0.02 65)` | `#A99A89` | 占位、辅助说明 |
| `ink-100` | `oklch(0.90 0.015 70)` | `#E4D9CB` | 描边、分隔线 |

规则:彩色只有杏色一族;状态色(成功/警示)默认用系统色,不新增品牌彩色。
白 `#FFFFFF` 只用于杏色底上的图形(爪印)与照片/视频内容本身。
`apricot-500` 与白色对比度约 2.6:1,**只用于大字号/图形,不用于正文**。

### 10.2 字体与层级

系统字体栈(中文 PingFang SC,英文 SF Pro 系),不引入三方字体。

| 层级 | 字重/字号(web px) | 用途 |
|---|---|---|
| Display | Bold 40–48 | 页面主张(一句话级) |
| Title | Semibold 28 | 小节标题 |
| Headline | Semibold 18 | 卡片标题、强调句 |
| Body | Regular 16–17 | 正文 |
| Caption | Regular 13–14 | 辅助说明、日期标签 |

数字用 `font-variant-numeric: tabular-nums`;行高:标题 1.2,正文 1.6。

### 10.3 圆角、间距与质感

| Token | 值 | 用途 |
|---|---|---|
| `radius-s` | 12 | 小元素:标签、缩略图、输入框 |
| `radius-m` | 20 | 卡片、照片容器 |
| `radius-l` | 28 | 大卡片、模态、视频占位框 |
| `radius-pill` | 999 | 按钮、胶囊标签 |

间距基于 4pt 网格,常用 8 / 12 / 16 / 24 / 32 / 48;卡片内边距 ≥20,段落间距 ≥24。

- **阴影**:只用一层极软的暖阴影,如 `0 8px 24px rgba(70,55,40,0.08)`;禁止多重硬阴影、禁止玻璃拟态堆叠。
- **渐变**:品牌渐变固定方向 135°,`apricot-400 → apricot-600`(同图标);界面内少用大渐变,主要留给图标、插画与 CTA。
- **描边**:1px `ink-100`,用于卡片边界;不用深色描边。
- **插画风格**:纯色剪影 + 半透明叠加(呼应「同角度叠加」的核心玩法),不描线稿、不贴贴纸。
- **照片内容**(宠物照片本身)永远是视觉主角,界面元素退后,不加花纹抢戏。

### 10.4 组件基调

- 主按钮:pill 形,`apricot-500` 底 + 白字,按压缩到 `apricot-600`,圆角全满。
- 卡片:`#FFFFFF` 或 `cream-100` 底,`radius-m/l`,软阴影或 1px `ink-100` 描边二选一。
- 输入框:`radius-s`,`ink-100` 描边,聚焦态描边变 `apricot-500`。
- 空状态/占位:`peach-100` 底 + 杏色剪影图形,不用灰色叉叉图。
